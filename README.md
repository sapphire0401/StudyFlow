# StudyFlow

一个运行在 Windows 桌面上的轻量待办与灵感记录组件。它把日常计划放在桌面上，方便随时查看和记录。

## 功能

- 日、周、月视图，按日期查看和管理记录
- 子弹笔记式记录：待办、事件和灵感使用不同符号区分
- 任务完成、编辑和删除
- 透明度、窗口尺寸、锁定状态和图层顺序设置
- 系统托盘、开机启动
- 从剪贴板粘贴图片，在组件中查看缩略图和大图
- 图片和文件暂存（功能仍在持续完善，建议使用前先确认当前版本的导入方式）

## 技术栈

- Electron
- JavaScript
- HTML / CSS

## 本地运行

需要先安装 Node.js。克隆项目后，在项目目录运行：

```bash
npm install
npm start
```

## Windows 打包

项目配置了 Windows 打包脚本时，可运行：

```bash
npm run make:win
```

生成的安装包位置以终端输出和项目打包配置为准。

## 使用说明

- 通过组件中的 `+` 添加记录。
- 点击待办圆圈标记完成；右键记录可使用编辑或删除操作（以当前版本界面为准）。
- 复制图片后，先点击 StudyFlow 使窗口获得焦点，再按 `Ctrl+V`；也可使用系统托盘中的“粘贴剪贴板图片”。
- 锁定、尺寸、透明度和图层选项可在设置中调整。
